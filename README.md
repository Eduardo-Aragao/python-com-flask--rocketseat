Esta é uma API REST desenvolvida durante o curso introdutório de Python com Flask da **Rocketseat**. O projeto simula o back-end de um e-commerce, permitindo o gerenciamento de produtos, carrinho de compras e processos de checkout.

---

## 🛠️ Funcionalidades

A API conta com os seguintes recursos:

- **Gerenciamento de Usuários:** Cadastro e autenticação segura.
- **Catálogo de Produtos:** Listagem, visualização de detalhes, adição e remoção de produtos.
- **Carrinho de Compras:** Adição de itens ao carrinho e persistência por usuário.
- **Checkout:** Finalização de pedidos e simulação de compra.
- **Segurança:** Proteção de rotas utilizando login e controle de sessão.

---

## 🧰 Tecnologias Utilizadas

- **[Python](https://www.python.org/):** Linguagem principal.
- **[Flask](https://flask.palletsprojects.com/):** Micro-framework web.
- **[Flask-Login](https://flask-login.readthedocs.io/):** Gerenciamento de autenticação de usuários.
- **[Flask-SQLAlchemy](https://flask-sqlalchemy.palletsprojects.com/):** ORM para manipulação do banco de dados SQLite.
- **[SQLite](https://sqlite.org/index.html):** Banco de dados relacional leve para desenvolvimento.
